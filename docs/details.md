>

> 1. 总体风险等级

> 1. 强制准入要求
> 2. 处罚条款
> 3. 与中国合规差异点
> 4. 企业可执行合规动作
>
> 仅限来源：商务部、贸促会、目的国官方、权威律所官网。

**（3）机构推荐**

> 根据 {企业规模/出海预算/具体需求}，从合规机构库筛选最优匹配。
>
> 输出：
> 1. 合规要求（分场景）

#### 国外成员上传机制

- **需要**：是
- **形式**：表单 / 表格 + 权限后台 + AI 自动入库
- **权限**：境外成员仅可新增 / 编辑，不可删除，后台审核
- **字段**：国家、领域、条款、生效日期、来源链接、附件
- **机制**：AI 抓取 + 人工提交 + 双重审核 → 入库 → 报告自动更新

#### 机构更新机制

**会更新，具体方式：**

1. **动态评级**
    - 每季度自动刷新：政府评级、公开榜单、客户评价、服务质量

2. **新增入库**
    - 企业推荐、境外成员上报、合作律所推荐、AI 爬虫抓取

3. **退出机制**
    - 投诉 ≥ 2 次、评级降至 C 以下、违规曝光 → 暂停推荐

4. **AI 系统同步**
    - 机构库变动 → 实时同步匹配模型 → 报告自动使用最新数据
